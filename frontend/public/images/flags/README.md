# Language flags

SVG source: https://flagcdn.com/ (same source as the original German flag).
Downloaded 2026-11-15. Files are served locally, without runtime third-party requests.

Language → country: de → DE, en → GB, pl → PL, fr → FR, es → ES,
it → IT, pt → PT, nl → NL, sv → SE, no/nb/nn → NO, da → DK,
fi → FI, cs → CZ, uk → UA, ru → RU, tr → TR, el → GR, ja → JP,
ko → KR, zh → CN.

The current set uses one representative flag per language. Locale variants
fall back to the base language (e.g. pl-PL → pl, en-US → en → GB).
Unknown or empty codes display a neutral language icon. Mapping lives in
src/utils/languageFlags.js; labels and user-defined names do not affect it.
